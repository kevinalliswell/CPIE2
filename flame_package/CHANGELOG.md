# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.2] - 2026-04-12

### Added
- GitHub Actions workflow for automated releases.
- Standard `.gitignore` for Python projects.

### Changed
- **Optimization**: Significant performance improvement in high-speed capture by implementing a memory buffering strategy.

## [1.1.1] - 2026-04-12

### Changed
- Optimized high-speed capture with memory buffering to improve FPS stability.
- Initial standalone repository release.

## [1.0.0] - 2025-11-21

### Added
- Initial version of FlameKit.
- Support for MindVision industrial cameras (MVSDK).
- Automatic flame analysis and length measurement.
- Calibration management per resolution.
