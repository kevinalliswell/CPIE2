===============================================================================
          FlameKit v1.0.0
          工业相机火焰检测工具包
===============================================================================

欢迎使用FlameKit！

本包提供基于迈德威视工业相机的火焰长度检测完整解决方案。


===============================================================================
快速开始 - 三步上手
===============================================================================

步骤1: 安装相机SDK
--------------
Windows: 从迈德威视官网下载并安装MVSDK
Linux: 安装libMVSDK.so到系统库路径

官网: http://www.mindvision.com.cn/


步骤2: 安装Python包
--------------
打开终端/命令提示符，进入本目录，执行：

    pip install -r requirements.txt
    pip install -e .


步骤3: 运行测试
--------------
进入 examples 目录，运行快速开始示例：

    cd examples
    python quick_start.py

===============================================================================
最简单的使用示例
===============================================================================

以下是最简单的使用代码：

    from flamekit import FlameKit
    
    kit = FlameKit()
    
    try:
        # 初始化相机
        kit.initialize()
        
        # 预览（可选）
        kit.preview(seconds=3.0)
        
        # 采集1秒图像
        images, count = kit.capture_one_second()
        print(f"采集了 {count} 帧")
        
        # 分析火焰
        result, max_image = kit.analyze()
        print(f"火焰长度: {result['max_length_mm']:.2f} mm")
        
        # 播放结果
        kit.play_analyzed()
        
        # 保存结果
        kit.save_max_result()
    finally:
        kit.release()

===============================================================================
配置文件 (config.json)
===============================================================================

首次运行时自动创建，主要参数：

相机参数:
  • exposure_us: 曝光时间（微秒）
  • resolution_index: 分辨率索引
  • force_mono: 强制单色模式

标定参数:
  • mm_per_pixel: 每像素对应的毫米数

分析参数:
  • binary_threshold: 二值化阈值
  • min_flame_area: 最小火焰面积

===============================================================================
常见问题
===============================================================================

Q: 找不到相机？
A: 检查相机连接、驱动安装、USB/网线

Q: 图像过亮/过暗？
A: 调整config.json中的exposure_us参数

Q: 检测不到火焰？
A: 调整binary_threshold和min_flame_area参数

Q: 测量不准确？
A: 运行calibration_demo.py进行参数标定

Q: 帧率太低？
A: 增大resolution_index（降低分辨率）
