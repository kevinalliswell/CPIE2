# FlameKit 简明使用手册

快速上手指南，5分钟开始使用 FlameKit。

## 安装（3步）

### 1. 安装相机SDK
- Windows: 从迈德威视官网下载并安装 MVSDK
- Linux: 安装 libMVSDK.so 到系统库路径

### 2. 安装Python包
```bash
pip install -r requirements.txt
pip install -e .
```

### 3. 运行测试
```bash
cd examples
python quick_start.py
```

## 最简单的使用（10行代码）

```python
from flamekit import FlameKit

kit = FlameKit()
kit.initialize()
images, count = kit.capture_one_second()
result, max_img = kit.analyze()
print(f"火焰长度: {result['max_length_mm']:.2f} mm")
kit.save_max_result()
kit.release()
```

## 完整流程

### 1. 初始化
```python
from flamekit import FlameKit

kit = FlameKit()
kit.initialize()  # 初始化相机
```

### 2. 预览（可选）
```python
kit.preview(seconds=3.0)  # 预览3秒，按ESC退出
```

### 3. 采集图像
```python
images, count = kit.capture_one_second()  # 采集1秒
print(f"采集了 {count} 帧")
```

### 4. 分析火焰
```python
result, max_img = kit.analyze()
if result['success']:
    print(f"长度: {result['max_length_mm']:.2f} mm")
    print(f"宽度: {result['max_width_mm']:.2f} mm")
```

### 5. 保存结果
```python
kit.save_max_result()  # 保存到 results/ 目录
```

### 6. 释放资源
```python
kit.release()  # 必须调用
```

## 参数标定

### 方法1: 使用标定工具（推荐）

```bash
cd examples
python calibration_demo.py
```

按提示操作：
1. 在相机视野中放置已知长度的参考物（如标尺）
2. 点击参考物的起点和终点
3. 输入实际长度（毫米）
4. 标定参数自动保存

### 方法2: 手动计算

```python
# 假设100mm的参考物在图像中占317像素
mm_per_pixel = 100.0 / 317.0  # 约 0.3152
kit.set_calibration(mm_per_pixel)
```

## 配置调整

配置文件位置（按优先级）：
1. `./config.json` (当前目录)
2. `~/.flamekit/config.json` (用户目录)
3. 包内默认配置

### 常用参数

**相机参数**:
```json
{
  "camera": {
    "exposure_us": 4000,      // 曝光时间（微秒）
    "resolution_index": 1,    // 分辨率索引（越大分辨率越低）
    "force_mono": true        // 强制单色模式
  }
}
```

**分析参数**:
```json
{
  "analysis": {
    "binary_threshold": 0,    // 二值化阈值
    "min_flame_area": 1000,   // 最小火焰面积（像素²）
    "use_otsu": true         // 使用OTSU自动阈值
  }
}
```

### 代码中修改配置

```python
# 修改曝光时间
kit.config.set('camera.exposure_us', 5000)

# 修改最小火焰面积
kit.config.set('analysis.min_flame_area', 500)
```

## 常见问题速查

### Q: 找不到相机？
- 检查USB/网线连接
- 确认驱动已安装
- 关闭其他使用相机的程序

### Q: 图像过亮/过暗？
```python
# 调整曝光时间
kit.config.set('camera.exposure_us', 3000)  # 降低曝光（变暗）
kit.config.set('camera.exposure_us', 6000)  # 增加曝光（变亮）
```

### Q: 检测不到火焰？
```python
# 降低最小面积阈值
kit.config.set('analysis.min_flame_area', 500)

# 调整二值化阈值
kit.config.set('analysis.binary_threshold', 30)
```

### Q: 测量不准确？
- 运行 `calibration_demo.py` 重新标定
- 确保参考物与火焰在同一平面
- 检查标定参数是否正确

### Q: 帧率太低？
```python
# 降低分辨率（增大索引）
kit.config.set('camera.resolution_index', 2)
```
