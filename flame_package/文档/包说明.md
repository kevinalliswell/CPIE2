# FlameKit 包说明

FlameKit 是一个专为工业相机火焰检测设计的 Python 工具包，提供简洁的 API 和完整的解决方案。

## 包特性

### 核心功能

✅ **高速图像采集**
- 支持 30-300+ FPS 高速采集
- 自动管理临时文件
- 可配置采集参数

✅ **火焰图像分析**
- 自动检测火焰轮廓
- 计算火焰长度、宽度、面积
- 像素到毫米的精确转换
- 自动标注分析结果

✅ **参数标定**
- 交互式标定工具
- 支持已知参考物标定
- 自动保存标定参数

✅ **实时预览与回放**
- 实时相机画面预览
- 慢动作回放分析结果
- 可调节播放速度

✅ **配置管理**
- 三级配置优先级
- 自动配置文件生成
- 运行时参数调整

### 设计原则

🎯 **最小可用原则**
- 提供核心功能，避免过度封装
- 简洁的 API 设计
- 易于集成到现有项目

🔧 **灵活配置**
- 支持多级配置优先级
- 运行时参数调整
- 配置文件自动管理

📦 **标准包结构**
- 支持 pip 安装
- 符合 Python 包规范
- 完整的文档和示例

## 技术架构

### 模块结构

```
flamekit/
├── __init__.py          # 包接口和版本
├── core.py              # 核心API (FlameKit类)
├── camera.py            # 相机采集封装
├── analyzer.py          # 火焰图像分析
├── config.py            # 配置管理
├── mvsdk.py             # 相机SDK封装
└── config_default.json  # 默认配置
```

### 依赖关系

```
FlameKit (core.py)
    ├── CameraCapture (camera.py)
    │   └── mvsdk (mvsdk.py)
    ├── FlameAnalyzer (analyzer.py)
    │   └── ConfigManager (config.py)
    └── ConfigManager (config.py)
```

### 工作流程

```
初始化相机 → 采集图像 → 分析火焰 → 保存结果
     ↓           ↓          ↓          ↓
  mvsdk      camera.py   analyzer.py  results/
```
