# 切线法独立对话框实现方案

## 问题分析

### 原方案的致命缺陷

**时间轴错位问题**：

```
主界面图表（实时显示）：
- 数据来源：deque(maxlen=200)
- 时间范围：最近1.67分钟（88.3-90分钟）
- 时间轴：[0, 0.5, 1.0, ..., 100秒]  ← 相对时间，起点=88.3分钟

切线法分析数据（从数据库）：
- 数据来源：数据库完整数据
- 时间范围：整个实验（0-90分钟）
- 时间轴：[0, 30, 60, ..., 5400秒]  ← 绝对时间，起点=0分钟
- 着火点时刻：1800秒（30分钟）

结果：
如果在主图表上绘制切线：
  - 主图表x轴范围：0-100秒
  - 切线位置：x=1800秒
  - 完全不可见或位置错乱！❌
```

**示意图**：

```
主图表（deque数据，88.3-90分钟）：
x轴: [0 ──────────────────────→ 100]秒
温度: [580 ───────────────────→ 600]°C
            ↑ 尝试绘制切线
        切线x=1800秒？超出范围！

独立对话框（数据库数据，0-90分钟）：
x轴: [0 ──────────────────────────────→ 5400]秒
温度: [25 ───→ 350 ──────────────────→ 600]°C
              ↑ 着火点
          t=1800秒，完美显示！✓
```

## 解决方案：独立对话框

### 核心设计思想

**完全独立，数据统一**：
- 不在主界面图表上绘制切线
- 创建独立的分析对话框
- 所有数据从数据库读取（时间轴统一）
- 完整展示整个实验过程

### 架构设计

```
用户点击"停止实验"
    ↓
停止数据采集
    ↓
弹出"切线法分析对话框"（TangentAnalysisDialog）
    │
    ├─ 从数据库读取完整数据
    ├─ 创建6个标签页（每个样品一个）
    ├─ 独立图表显示每个样品的分析结果
    └─ 所有数据基于统一的时间轴
```

## 实现细节

### 1. 对话框类结构

```python
class TangentAnalysisDialog(QDialog):
    """切线法分析对话框"""
    
    def __init__(self, session_id, db, config, parent=None):
        # session_id: 实验会话ID
        # db: 数据库实例
        # config: 配置字典
        pass
    
    def _perform_analysis(self):
        """执行分析"""
        # 1. 从数据库读取完整数据
        session_data = self.db.get_session_temperature_data(session_id)
        
        # 2. 构建时间和温度数组（统一时间轴）
        time_seconds = [record['elapsed_seconds'] for record in session_data]
        time_minutes = time_seconds / 60.0
        
        # 3. 对每个样品执行切线法检测
        for i in range(6):
            temp_array = [record[f'sample{i+1}_temperature'] for record in session_data]
            result = detector.detect_ignition(time_seconds, temp_array)
            
            # 4. 更新UI和绘图
            self._update_result_label(i, result)
            self._plot_analysis_result(i, time_minutes, temp_array, result)
    
    def _plot_analysis_result(self, channel, time_minutes, temp_array, result):
        """绘制分析结果"""
        # 温度曲线
        plot.plot(time_minutes, temp_array)
        
        # 基线（延伸）
        baseline_time = linspace(baseline_start, ignition_time + 3min)
        baseline_temp = k1 * baseline_time + b1
        plot.plot(baseline_time, baseline_temp, style='--', color='red')
        
        # 峰顶线（延伸）
        peak_time = linspace(ignition_time - 3min, peak_end)
        peak_temp = k2 * peak_time + b2
        plot.plot(peak_time, peak_temp, style=':', color='blue')
        
        # 着火点标记
        plot.scatter([ignition_time], [ignition_temp], marker='star')
```

### 2. 调用方式

```python
# 在 ignition_page.py 中
def _on_stop(self):
    """停止实验"""
    # 停止采集
    self.controller.stop_experiment()
    
    # 弹出切线法分析对话框
    if self.config['ignition_detection'].get('post_analysis', True):
        self._show_tangent_analysis_dialog()

def _show_tangent_analysis_dialog(self):
    """显示切线法分析对话框"""
    dialog = TangentAnalysisDialog(
        session_id=self.current_session_id,
        db=self.db,
        config=self.config,
        parent=self
    )
    dialog.exec()  # 模态对话框
```

## 优势对比

### 原方案（在主图表上绘制）

| 特性 | 评价 | 问题 |
|------|------|------|
| 数据来源 | deque | 数据不完整 ❌ |
| 时间轴 | 相对时间 | 与切线时间轴不匹配 ❌ |
| 可视化 | 混合显示 | 6个样品切线重叠混乱 ❌ |
| 用户体验 | 实时更新 | 信息过载，难以分辨 ❌ |

### 新方案（独立对话框）

| 特性 | 评价 | 优势 |
|------|------|------|
| 数据来源 | 数据库 | 完整数据 ✓ |
| 时间轴 | 统一绝对时间 | 完美匹配 ✓ |
| 可视化 | 独立标签页 | 每个样品清晰独立 ✓ |
| 用户体验 | 专注分析 | 信息结构化，易于理解 ✓ |
| 功能扩展 | 独立窗口 | 可添加更多功能（导出、打印） ✓ |

time_seconds = np.array([record['elapsed_seconds'] for record in session_data])
