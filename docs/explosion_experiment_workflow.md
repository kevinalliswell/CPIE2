### 按钮功能说明

| 按钮 | 功能 | 会话状态变化 | 数据保留 |
|------|------|-------------|---------|
| 连接设备 | 连接温控、压力、继电器设备 | - | - |
| 新建实验 | 创建新的实验会话 | → running | 清空内存 |
| 启动实验 | 开始一轮实验（拍照+时序+分析） | running | 轮次+1 |
| 停止实验 | 停止当前轮次 | running (不变) | 保留 |
| 完成实验 | 结束会话并保存结果 | running → completed | 清空内存 |

## 实验会话管理

### 会话状态

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| running | 会话活跃，可继续实验 | 启动实验、完成实验 |
| completed | 会话已完成 | 查看历史、导出数据 |
| ~~stopped~~ | (不再使用) | ~~已改为保持running~~ |

### 停止 vs 完成

```
┌─────────────────────────────────────────────────────────┐
│                 停止实验 vs 完成实验                      │
└─────────────────────────────────────────────────────────┘

停止实验:
  - 目的: 中断当前轮次
  - 会话状态: running (不变)
  - 数据: 保留所有已完成轮次
  - 后续: 可以继续启动下一轮
  - 用途: 紧急停止、设备故障、临时中断

完成实验:
  - 目的: 结束整个会话
  - 会话状态: running → completed
  - 数据: 
    ├─ 计算平均火焰长度
    ├─ 分类爆炸性等级
    ├─ 保存到 experiment_results 表
    └─ 清空内存记录
  - 后续: 可以新建下一个实验
  - 用途: 主动结束、样品不合格、已测够轮次
```

## 数据结构

### 实验会话表 (experiment_sessions)

```python
{
    'id': int,                    # 会话ID (自增)
    'start_time': datetime,       # 开始时间
    'end_time': datetime,         # 结束时间 (完成时填入)
    'experiment_name': str,       # 实验名称
    'sample_name': str,           # 样品名称
    'client': str,                # 委托单位
    'operator': str,              # 操作员
    'description': str,           # 描述
    'status': str                 # 状态: running/completed
}
```

### 测试轮次表 (test_rounds)

```python
{
    'id': int,                       # 记录ID (自增)
    'session_id': int,               # 会话ID (外键)
    'round_number': int,             # 轮次编号 (1-10)
    'flame_length': float,           # 火焰长度(mm)
    'max_flame_image_path': str,     # 最大火焰图片路径
    'timestamp': datetime            # 记录时间
}
```

### 实验结果表 (experiment_results)

```python
{
    'id': int,                    # 结果ID (自增)
    'session_id': int,            # 会话ID (外键)
    'total_rounds': int,          # 总测试轮次 (5 或 10)
    'avg_flame_length': float,    # 平均火焰长度(mm)
    'explosion_level': str,       # 爆炸性等级
    'timestamp': datetime         # 完成时间
}
```

## 代码示例

### 完整实验流程

```python
from models.explosion_database import ExplostionDatabase

# 初始化数据库
db = ExplostionDatabase("explosion_experiment.db")

# 1. 开始实验会话
session_id = db.start_experiment_session(
    experiment_name="煤粉爆炸性测试",
    sample_name="煤样A",
    client="某煤矿",
    operator="张三",
    description="测试煤样A的爆炸性特征"
)

print(f"会话ID: {session_id}")

# 2. 前5轮测试
for i in range(1, 6):
    print(f"\n=== 第 {i} 轮测试 ===")
    
    # 执行实验
    # - 高速拍照
    # - 时序控制
    # - 火焰分析
    
    flame_length = measure_flame_length()  # 从分析器获取
    image_path = get_max_flame_image()     # 从max_flame_images
    
    # 保存轮次数据
    db.add_test_round(session_id, i, flame_length, image_path)
    print(f"火焰长度: {flame_length}mm")

# 3. 计算前5轮平均值
avg_length = db.calculate_session_average(session_id)
print(f"\n前5轮平均火焰长度: {avg_length}mm")

# 4. 判断是否需要继续测试
if avg_length < 20:
    print("平均值低于20mm，继续后5轮测试...")
    
    # 继续后5轮测试
    for i in range(6, 11):
        print(f"\n=== 第 {i} 轮测试 ===")
        flame_length = measure_flame_length()
        image_path = get_max_flame_image()
        db.add_test_round(session_id, i, flame_length, image_path)
        print(f"火焰长度: {flame_length}mm")
    
    # 重新计算平均值
    avg_length = db.calculate_session_average(session_id)
    print(f"\n10轮平均火焰长度: {avg_length}mm")

# 5. 完成实验（点击"完成实验"按钮）
success = db.finalize_experiment(session_id)

if success:
    # 6. 查询结果
    result = db.get_session_result(session_id)
    print("\n实验完成！")
    print(f"爆炸性等级: {result['explosion_level']}")
    print(f"平均火焰长度: {result['avg_flame_length']}mm")
    print(f"总测试轮次: {result['total_rounds']}")
```

## 检测标准符合性判断

```
┌────────────────────────────────────────────────────────┐
│              检测标准符合性判定规则                      │
└────────────────────────────────────────────────────────┘

检测标准要求：满足以下任一条件即可

✓ 条件1: 前5轮平均值 ≥ 20mm
   └─ 说明: 样品具有爆炸性，可提前结束测试

✓ 条件2: 完成10轮完整测试
   └─ 说明: 已完成完整检测流程，无论结果如何都算合格

⚠ 不满足标准的情况：
   └─ 前5轮平均值 < 20mm 且用户选择不继续测试
      └─ 结论: 不满足检测标准要求

实验流程判断：
┌─────────────────────────────────────┐
│ 第5轮完成                            │
│   ↓                                 │
│ 计算 avg_length = 前5轮平均值       │
│   ↓                                 │
│ if avg_length >= 20:                │
│    ✓ 满足标准 → 可选择结束          │
│ else:                               │
│    ⚠ 不满足标准 → 提示继续6-10轮    │
│    ├─ 继续: 完成10轮后满足标准      │
│    └─ 拒绝: 不满足检测标准要求      │
└─────────────────────────────────────┘
```
