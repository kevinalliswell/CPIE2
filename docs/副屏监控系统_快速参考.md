### 1. 控制器新增信号

#### `explosion_controller.py`
```python
# 新增7个信号用于副屏订阅
temp_controller_updated = Signal(dict)      # 温控器数据

```

#### `ignition_controller.py`
```python
# 新增5个信号用于副屏订阅
control_temp_controller_updated = Signal(dict)  # 温控器数据
sample_temps_updated = Signal(list)             # 样品温度

device_status_changed = Signal(str, bool)       # 设备状态
```

### 2. 控制器新增方法

```python
# 数据监控管理
controller.start_data_monitoring()   # 启动数据监控
controller.stop_data_monitoring()    # 停止数据监控

# 内部方法
controller._poll_device_data()       # 轮询设备数据
controller._update_state(state)      # 更新实验状态
```

### 3. 副屏窗口新增方法

```python
# 在 secondary_display_window.py 中
window._start_controllers_monitoring()  # 启动控制器监控
window._stop_controllers_monitoring()   # 停止控制器监控
```

### 4. 主窗口新增方法

```python
# 在 main_window.py 中
main_window._get_explosion_controller()  # 获取爆炸性控制器
main_window._get_ignition_controller()   # 获取着火点控制器
```

## 🔌 信号数据格式

### 温控器数据
```python
{
    'pv': float,      # 当前值 (Process Value)
    'sv': float,      # 设定值 (Set Value)
    'mv': float,      # 输出值 (Manipulated Value)
    'status': str     # 状态 ('在线'/'离线')
}
```

### 样品温度数据
```python
[temp1, temp2, temp3, temp4, temp5, temp6]  # 6路温度，list[float]
```

{

## 🐛 常见问题速查

### 问题：副屏无数据显示
```python
# 检查点1: 数据监控是否启动
controller.data_monitor_timer.isActive()  # 应该返回 True

# 检查点2: 信号是否连接
# 查看控制台输出: "[XX监控面板] 控制器信号已连接"

# 检查点3: 设备数据是否有效
data = controller.get_latest_controller_data()
print(data)  # 应该有数据
```

### 问题：数据更新延迟
```python
# 调整更新间隔（在控制器初始化中）
self.data_monitor_timer.setInterval(200)  # 改为200ms（更快）
```
