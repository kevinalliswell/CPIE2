## 📝 修改的文件

### 1. `src/views/main_window.py`

**修改内容**:
- 在 `closeEvent()` 方法中添加了关闭副屏窗口的逻辑
- 确保主窗口关闭时，副屏窗口同步关闭

**新增代码**:
```python
# 关闭副屏窗口
if self.secondary_display_window is not None:
    try:
        self.secondary_display_window.close()
        self.logger.info("副屏窗口已关闭")
    except Exception as e:
        self.logger.error(f"关闭副屏窗口失败: {e}")
```

**修改内容**:
- 启用了 `_apply_styles()` 方法调用
- 新增 `_apply_styles()` 方法实现（加载亮色样式）
- 新增 `_apply_fallback_style()` 方法（后备样式）

**新增方法**:
- `_apply_styles()` - 加载和应用副屏亮色样式
- `_apply_fallback_style()` - 应用后备样式（当主样式文件加载失败时）

如果样式文件不存在：

如需自定义样式：
1. 编辑 `resources/styles/secondary_display_light.qss`
2. 修改相应的 CSS 样式规则
3. 重启程序即可生效
