# CPIE v1.2.1 — 软件收敛发布

发布日期：2026-09-30。目标平台：Windows 10/11 64 位。

本版本结束本轮软件修复与整理。维护者决定先合并发版，后续再做真机验收。**真实仪表、继电器、相机及完整实验流程尚未现场验收。**

## 主要更新

- 修复未开启实验、电脑未联机时退出被拦截的问题；曾联机或发出控制时仍保留停止确认和重试。
- 设备指令等待实际执行结果，停止阻断旧启动命令；保存失败保留实验会话，异常退出后恢复历史数据。
- 相机采集移入后台，预览/标定/采集互斥；喷吹与首帧、采集窗口检查配合，失败和旧回调不能产生有效轮次。
- 历史按实验类型和 ID 定位；最大火焰与平均值分别展示，曲线关联真实会话，数据库备份包含 WAL。
- 温升计算使用实际采样时间，切线分析校验数值和时序并修正峰顶拟合；算法回归不代替标样验收。
- 口令使用随机盐哈希，支持旧明文迁移；写盘失败保留原口令，损坏配置不回退到默认口令。
- 修复配置重置引用、副屏刷新、Esc 回传分析结果、资源路径和日志重复等问题。

详细条目见 [CHANGELOG](../../CHANGELOG.md)，合并取舍见 [PR 收敛记录](../PR_CONSOLIDATION.md)。

## 下载与验证

从 [v1.2.1 Release 页面](https://github.com/kevinalliswell/CPIE2/releases/tag/v1.2.1) 下载完整 Windows ZIP，配套 `_info.json` 和 `.zip.sha256` 用于核对源码版本与摘要。

发布工作流对标签指向的源码运行应用测试、固定 FlameKit 测试、源码和冻结 EXE 的启动/恢复/导出/离线退出检查，全部通过后才上传发布资产。此前 PR 候选是历史证据，正式包以该 Release 为准。

## 安装、升级与回退

1. 结束实验并关闭旧程序，备份 `data/`、`configs/`、`logs/`、`exports/` 及相机用户配置。
2. 用 PowerShell `Get-FileHash -Algorithm SHA256 <ZIP路径>` 与 `.zip.sha256` 核对，完整解压后运行 `install.bat`。
3. 默认安装到当前用户 `%LOCALAPPDATA%\Programs\CPIE`，升级保留已有数据和配置。
4. 先检查无设备启动/退出、设置和历史，再按 [实机验收记录](../HARDWARE_ACCEPTANCE.md) 做现场验证。

新版会升级旧口令存储格式；旧程序未必能读取新哈希。需要回退时，保留新版数据另作备份，再恢复升级前的程序及配套数据/配置，避免覆盖新增记录。

FlameKit 固定为 `f0c3e65c0c68b28e41b3e195764a8f0d0a1ab4bd`；其包元数据仍为 1.1.2，须按提交核对。Windows 包包含所需 Python 运行依赖，真实仪器驱动和相机 SDK 仍需现场配置。
