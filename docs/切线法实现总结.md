# 切线法着火点检测实现总结

## 实现概述

已成功实现基于 GB/T 18511-2017《煤的着火温度测定方法》的放热峰切线法着火点检测功能，作为系统原有实时检测方法的补充和验证。

## 完整流程分析

### 阶段一：实验过程中（实时检测）

```
启动实验 
    ↓
定时器每500ms采集温度数据
    ↓
温度数据存入历史缓存（deque，最多200个点）
    ↓
每200ms执行实时检测算法
    ↓
三种方法并行检测：
    ├─ 绝对温度法：temp >= 600°C
    ├─ 温度突升法：Δtemp >= 50°C (2秒内)
    └─ 温升速率法：dT/dt >= 30°C/s
    ↓
检测到着火点 → 标记、记录日志、写数据库
```

**特点**：
- 快速响应，实时监控
- 适合过程控制和报警
- 依赖参数设置

### 阶段二：实验结束时（切线法分析）

```
用户点击"停止实验"
    ↓
调用 _analyze_ignition_by_tangent_method()
    ↓
遍历6个样品通道
    │
    ├─ 通道1 ────┐
    ├─ 通道2     │
    ├─ 通道3     │
    ├─ 通道4     ├→ 并行处理
    ├─ 通道5     │
    └─ 通道6 ────┘
        │
        ↓
    每个通道独立执行：
        1. 数据验证（≥50个点）
        2. 数据平滑（Savitzky-Golay滤波）
        3. 计算一阶导数（温升速率）
        4. 计算二阶导数（加速度）
        5. 识别拐点（加速度显著增大点）
        6. 识别峰顶（温升速率最大值）
        7. 拟合基线（拐点前的线性段）
        8. 拟合峰顶线（峰顶附近的线性段）
        9. 计算交点（着火点）
        10. 计算置信度
        ↓
    结果处理：
        ├─ 更新UI标签（显示两种方法对比）
        ├─ 记录日志（记录差异）
        ├─ 更新数据库（存储切线参数）
        └─ 绘制图表（绘制切线和交点）
```

**特点**：
- 科学准确，符合国家标准
- 适合最终报告和数据归档
- 基于物理过程，不依赖经验阈值

## 配置参数

### 切线法参数（config.yaml）

```yaml
ignition_detection:
  enabled: true
  post_analysis: true  # 是否启用切线法事后分析
  tangent_method:
    smooth_window: 11  # 平滑窗口（奇数）
    smooth_order: 2  # 平滑多项式阶数
    baseline_points: 20  # 基线拟合点数
    peak_points: 10  # 峰顶拟合点数
    min_temp_rise: 20.0  # 最小温升（°C）
    min_rate_increase: 2.0  # 最小速率增幅
    min_data_points: 50  # 最小数据点数
```

### 参数调整建议

| 参数 | 默认值 | 调整建议 |
|------|--------|----------|
| smooth_window | 11 | 数据噪声大时增加到15-21 |
| baseline_points | 20 | 升温速率慢时增加到30-40 |
| peak_points | 10 | 放热峰尖锐时减少到5-8 |
| min_temp_rise | 20.0°C | 低温着火样品减少到10-15°C |
| min_rate_increase | 2.0 | 放热不明显时减少到1.5 |

### 新增字段

```sql

    id INTEGER PRIMARY KEY,
    session_id INTEGER,
    channel INTEGER,

    baseline_k REAL,  -- 基线斜率
    baseline_b REAL,  -- 基线截距
    peak_k REAL,  -- 峰顶斜率
    peak_b REAL,  -- 峰顶截距
```

### 查看结果

1. **实验过程中**：查看实时检测结果（温度标签红色显示）
2. **实验结束时**：
   - 查看切线法结果（温度标签绿色显示）
   - 查看图表上的切线和交点
   - 查看日志中的对比分析
3. **历史数据**：查询数据库获取完整结果

### 结果对比

系统会自动对比两种方法的结果：

```
样品1:
  实时检测: 388.5°C (温度突升法)
  切线法:   385.2°C (置信度0.95)
  差值:     3.3°C
```

**差值分析**：
- 差值 < 5°C：结果一致，可信度高
- 差值 5-10°C：存在偏差，建议以切线法为准
- 差值 > 10°C：可能存在问题，需要人工审核
