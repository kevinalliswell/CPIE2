# 爆炸性实验会话逻辑全面审查与改进计划

## 审查发现的问题

### 问题1：轮次数据双重保存导致数据库重复 🔴 严重

**位置**:

- [`src/views/pages/explosion_page.py:844-850`](src/views/pages/explosion_page.py) `_on_controller_sequence_completed()`
- [`src/views/pages/explosion_page.py:1152-1162`](src/views/pages/explosion_page.py) `_on_flame_analysis_complete()`

**问题**: 每轮实验会在数据库中产生两条记录（第一次保存0.0，第二次保存真实值）

---

### 问题2：火焰数据保存时机错误 🔴 严重

**位置**: [`src/views/pages/explosion_page.py:1532-1556`](src/views/pages/explosion_page.py)

**问题**: 时序完成后立即保存，此时火焰长度还是0.0和None

---

### 问题3：轮次计数不一致 🟡 中等

**问题**: Controller和UI维护两套轮次计数，可能不同步

---

### 问题4：stop_experiment会话状态处理不当 🟡 中等

**位置**: [`src/controllers/explosion_controller.py:314-316`](src/controllers/explosion_controller.py)

**问题**: 停止时将会话标记为'stopped'，但用户可能只是暂停当前轮

---

### 问题5：current_session_id清理时机混乱 🟡 中等

**问题**: 多处清理会话ID，逻辑不统一

---

### 问题6：round_records与数据库的同步问题 🟢 轻微

**问题**: 内存数组不从数据库加载，重启后丢失

---

### 问题7：会话进行中"新建实验"按钮未禁用 🔴 严重 ⭐新增

**位置**: [`src/views/pages/explosion_page.py:844-869`](src/views/pages/explosion_page.py)

**当前行为**:

- 完成第1轮后，"新建实验"按钮立即可用
- 用户可能误点创建新会话，导致current_session_id被覆盖
- 原会话数据丢失或混乱

**正确行为**:

- "新建实验"按钮只在以下情况启用：
                - 已连接设备且无活动会话
                - 会话已完成（finalized）

---

### 问题8：缺少"完成实验"功能 🟡 中等 ⭐新增

**当前状态**:

- 只能通过5轮或10轮完成后弹窗结束会话
- 无法主动结束进行中的会话
- "停止"和"完成"概念混淆

**需求**:

- 新增"完成实验"按钮
- 用户可在任意轮次后主动完成实验
- 清晰区分三个动作：
                - 停止实验：停止当前轮次（会话仍running）
                - 完成实验：结束会话并保存结果（会话变completed）
                - 新建实验：创建新会话（需要先完成当前会话）

---

### 修复2：统一轮次计数来源 ✅ 必须

### 修复3：改进stop_experiment逻辑 ✅ 必须

### 修复4：从数据库恢复round_records ✅ 推荐

### 修复5：新增"完成实验"按钮 ✅ 必须 ⭐新增

**UI布局**:

```
控制面板:
  [连接设备]  [新建实验]      ← 第1行
  [启动实验]  [停止实验]      ← 第2行  
              [完成实验]      ← 第3行（新增）
```

**按钮功能**:

```python
def _on_finalize_experiment(self):
    """完成实验按钮点击事件"""
    # 1. 检查是否有活动会话
    if not self.current_session_id:
        return
    
    # 2. 获取当前数据
    rounds = self.db.get_session_test_rounds(self.current_session_id)
    if not rounds:
        QMessageBox.warning(self, "提示", "当前会话没有测试数据")
        return
    
    # 3. 计算统计信息
    avg_length = self.db.calculate_session_average(self.current_session_id)
    explosion_level = self.db.classify_explosion_strength(avg_length)
    
    # 4. 确认对话框
    reply = QMessageBox.question(
        self,
        '完成实验',
        f'确定要完成当前实验吗？\n\n'
        f'实验名称: {self.current_exp_config["experiment_name"]}\n'
        f'已完成轮次: {len(rounds)}\n'
        f'平均火焰长度: {avg_length:.2f}mm\n'
        f'爆炸性等级: {explosion_level}\n\n'
        f'完成后将无法继续此会话。',
        QMessageBox.Yes | QMessageBox.No
    )
    
    if reply == QMessageBox.Yes:
        # 5. 调用finalize_experiment
        success = self.db.finalize_experiment(self.current_session_id)
        
        if success:
            # 6. 清理会话状态
            self.current_session_id = None
            self.current_exp_config = None
            self.current_round_number = 0
            self.round_records.clear()
            self._update_records_panel()
            
            # 7. 更新按钮状态
            self._update_button_states_after_finalize()
            
            # 8. 显示成功消息
            QMessageBox.information(
                self, "完成",
                f"实验已成功完成！\n\n"
                f"平均火焰长度: {avg_length:.2f}mm\n"
                f"爆炸性等级: {explosion_level}"
            )
```

### 修复6：优化按钮状态管理 ✅ 必须 ⭐新增

**状态机设计**:

```
状态1: 未连接
  - [连接设备]: 可用
  - 其他按钮: 全部禁用

状态2: 已连接，无会话
  - [连接设备]: 禁用
  - [新建实验]: 可用 ✓
  - 其他: 禁用

状态3: 会话已创建，未运行
  - [新建实验]: 禁用 ✓
  - [启动实验]: 可用
  - [完成实验]: 可用 ✓
  - [停止实验]: 禁用

状态4: 实验运行中
  - [新建实验]: 禁用 ✓
  - [启动实验]: 禁用
  - [停止实验]: 可用
  - [完成实验]: 禁用 ✓

状态5: 会话已完成
  - 回到状态2
```

**实现方法**:

创建统一的按钮状态更新方法：

```python
def _update_button_states(self):
    """统一更新所有按钮状态"""
    has_session = self.current_session_id is not None
    is_running = self.is_running or self.sequence_running
    is_connected = self.manager is not None
    
    # 连接按钮
    self.btn_connect.setEnabled(not is_connected)
    
    # 新建实验：只在已连接且无会话时可用
    self.btn_new_experiment.setEnabled(is_connected and not has_session)
    
    # 启动实验：有会话且未运行时可用
    self.btn_start.setEnabled(has_session and not is_running)
    
    # 停止实验：运行中时可用
    self.btn_stop.setEnabled(is_running)
    
    # 完成实验：有会话且未运行时可用
    self.btn_finalize.setEnabled(has_session and not is_running)
    
    # 自清洁按钮：未运行时可用
    self.btn_auto_clean_on.setEnabled(is_connected and not is_running)
    self.btn_auto_clean_off.setEnabled(is_connected and not is_running)
```

在所有状态变化点调用此方法：

- `_on_controller_device_connected()`
- `_on_controller_experiment_created()`
- `_on_controller_experiment_started()`
- `_on_controller_experiment_stopped()`
- `_on_controller_sequence_completed()`
- `_on_finalize_experiment()` (新增)
