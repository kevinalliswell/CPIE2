# 爆炸性实验"新建实验"按钮功能实现总结

## ✅ 已完成功能

### 1. UI 组件
- ✅ 添加"新建实验"按钮
- ✅ 按钮位置：连接设备 → **新建实验** → 启动实验 → 停止实验
- ✅ 按钮样式：蓝色背景 (#2196F3)
- ✅ 固定宽度：120px

### 2. 按钮状态管理
- ✅ 初始状态：禁用
- ✅ 连接成功后：启用
- ✅ 实验运行中：禁用
- ✅ 实验停止后：启用

### 3. 数据库集成
- ✅ 初始化数据库：`ExplostionDatabase("data/explosion_experiment.db")`
- ✅ 数据保存到 `data/` 目录
- ✅ 自动创建必要的表结构

### 4. 实验会话管理
- ✅ `current_session_id` - 当前会话ID
- ✅ `current_exp_config` - 当前实验配置
- ✅ `current_round_number` - 当前轮次编号

### 5. 核心方法实现

#### `_on_new_experiment()`
```python
功能：
- 生成实验编号 (EXP-YYYYMMDD-HHMMSS)
- 创建并显示参数对话框
- 接收配置并创建数据库会话
- 启用"启动实验"按钮
- 更新状态显示

异常处理：
- 对话框创建失败
- 数据库会话创建失败
```

#### `_on_start_experiment()`
```python
功能：
- 检查是否有活动会话
- 显示实验信息确认对话框
- 启动时序控制流程

验证：
- 必须先新建实验
- 实验不能重复运行
```

#### `_start_sequence()`
```python
功能：
- 增加轮次计数器
- 重置数据缓存
- 更新按钮状态
- 在新线程执行时序

状态管理：
- 启用停止按钮
- 禁用启动和新建按钮
```

#### `_save_test_round()`
```python
功能：
- 保存测试轮次数据到数据库
- 记录火焰长度和图片路径
- 显示保存结果

数据字段：
- session_id: 会话ID
- round_number: 轮次编号
- flame_length: 火焰长度(mm)
- max_flame_image_path: 图片路径
```

#### `_prompt_next_round()`
```python
功能：
- 根据轮次数判断流程
- 第5轮：检查平均值是否<20mm
- 第10轮：询问是否完成
- 其他：询问是否继续

逻辑判断：
if total_rounds == 5:
    if avg < 20: 提示继续后5轮
    else: 询问是否完成
elif total_rounds >= 10:
    询问是否完成
else:
    询问是否继续
```

#### `_ask_finalize_experiment()`
```python
功能：
- 计算平均火焰长度
- 分类爆炸性强弱
- 保存实验结果
- 清除会话状态
- 更新UI状态

结果保存：
- 调用 db.finalize_experiment()
- 保存到 experiment_results 表
- 更新 experiment_sessions 状态
```

#### `stop_experiment()`
```python
优化：
- 根据会话状态设置显示
- 保留会话信息
- 允许继续测试
- 启用新建实验按钮
```

## 📊 状态流转图

```
┌────────────┐
│ 应用启动    │
│ (未连接)    │
└─────┬──────┘
      │ 点击 [连接设备]
      ↓
┌────────────┐
│ 已连接      │  ← 启用 [新建实验]
└─────┬──────┘
      │ 点击 [新建实验]
      ↓
┌────────────┐
│ 填写参数    │  ← ExplosionExperimentDialog
└─────┬──────┘
      │ 确认
      ↓
┌────────────┐
│ 实验已创建  │  ← 启用 [启动实验]
│ (有会话ID)  │
└─────┬──────┘
      │ 点击 [启动实验]
      ↓
┌────────────┐
│ 实验运行中  │  ← 启用 [停止实验]
│ (第N轮)     │
└─────┬──────┘
      │ 自动完成
      ↓
┌────────────┐
│ 保存数据    │  ← _save_test_round()
└─────┬──────┘
      │
      ↓
┌────────────┐
│ 询问继续？  │  ← _prompt_next_round()
└─────┬──────┘
      │
      ├─ 继续 → 返回 [实验已创建]
      │
      └─ 完成 → _ask_finalize_experiment()
                    ↓
              ┌────────────┐
              │ 实验完成    │
              │ (无会话)    │
              └────────────┘
```
