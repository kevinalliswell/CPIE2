# 着火点检测功能详细说明文档

## 1. 功能概述

着火点检测功能是CPIE-3000A煤粉着火点及爆炸性检测系统的核心功能之一，用于实时监测6个煤粉样品的温度变化，自动检测并记录每个样品的着火点温度。系统采用多种检测方法相结合的方式，确保检测结果的准确性和可靠性。

### 1.1 功能特点

- **多通道同时监测**：支持6个样品通道同时进行着火点检测
- **多方法检测**：采用三种检测方法（绝对温度法、温度突升法、温升速率法）相结合
- **实时数据采集**：实时采集温度数据并绘制温度曲线
- **自动记录**：检测到着火点后自动记录到数据库并更新UI显示
- **可配置参数**：所有检测参数均可通过配置文件进行调整

### 1.2 应用标准

本功能遵循 **GB/T 18511-2017《煤的着火温度测定方法》** 国家标准，确保检测结果符合行业规范。

## 2. 工作原理

### 2.1 检测流程

着火点检测功能的工作流程如下：

```
实验启动 → 温度数据采集 → 数据缓存 → 检测判断 → 标记着火点 → 记录数据
```

1. **实验启动**：用户点击"启动实验"按钮后，系统开始采集温度数据
2. **温度数据采集**：系统以500ms间隔从温度模块读取6个通道的温度数据
3. **数据缓存**：温度数据存储到历史缓存中（最多200个数据点）
4. **检测判断**：系统以200ms间隔执行检测算法，判断是否达到着火点
5. **标记着火点**：检测到着火点后，更新UI显示、记录日志、保存数据库
6. **记录数据**：着火点温度自动保存到数据库，供后续查询和分析

### 2.2 数据采集机制

- **采集频率**：UI更新定时器每500ms触发一次数据更新
- **检测频率**：着火点检测每200ms执行一次（可配置）
- **数据缓存**：每个通道最多保存200个温度数据点
- **采集起始温度**：默认200°C以下不采集数据到数据库（可配置）

## 3. 检测方法详解

系统采用三种检测方法，按优先级顺序执行，任一方法满足条件即判定为着火点。

### 3.1 方法一：绝对温度法

**原理**：当样品温度达到或超过预设的绝对温度阈值时，判定为着火点。

**适用场景**：适用于已知样品着火温度范围的情况，可作为安全上限。

**参数配置**：
- `enabled`: 是否启用此方法（默认：true）
- `threshold`: 绝对温度阈值（默认：600.0°C）

**检测条件**：
- 当前温度 ≥ 阈值
- 需要至少5个历史数据点

**优点**：
- 简单直接，易于理解
- 可作为安全保护机制

**缺点**：
- 不同样品的着火温度差异较大，单一阈值可能不够准确

### 3.2 方法二：温度突升法

**原理**：在指定时间窗口内，温度上升超过预设阈值时，判定为着火点。

**适用场景**：适用于大多数煤粉样品，是主要的检测方法。

**参数配置**：
- `enabled`: 是否启用此方法（默认：true）
- `threshold`: 温升阈值（默认：50.0°C）
- `time_window`: 时间窗口（默认：2.0秒）

**检测条件**：
- 时间窗口内温升 ≥ 阈值
- 需要至少10个历史数据点（或window_size个点）

**计算公式**：
```
window_size = time_window / check_interval
temp_rise = 当前温度 - temp_history[-window_size]
if temp_rise >= threshold: 判定为着火点
```

**优点**：
- 能够捕捉温度突然上升的特征
- 符合煤粉着火的实际物理过程

**缺点**：
- 需要足够的历史数据点
- 时间窗口设置需要根据升温速率调整

### 3.3 方法三：温升速率法

**原理**：当温度上升速率超过预设阈值时，判定为着火点。

**适用场景**：适用于快速升温或需要高灵敏度检测的情况。

**参数配置**：
- `enabled`: 是否启用此方法（默认：true）
- `threshold`: 温升速率阈值（默认：30.0°C/秒）

**检测条件**：
- 温升速率 ≥ 阈值
- 需要至少3个历史数据点

**计算公式**：
```
time_diff = check_interval * 2  (最近3个点的时间间隔)
temp_diff = 当前温度 - temp_history[-3]
rise_rate = temp_diff / time_diff
if rise_rate >= threshold: 判定为着火点
```

**优点**：
- 检测速度快，响应灵敏
- 能够捕捉快速升温过程

**缺点**：
- 可能受到温度波动影响
- 需要合理设置阈值避免误判

## 4. 配置参数说明

### 4.1 配置文件位置

配置文件路径：`configs/experiment_config.yaml`

### 4.2 参数详解

```yaml
ignition_experiment:
  collect_start_temperature: 200.0  # 数据采集起始温度（°C）
  ignition_detection:
    enabled: true                    # 是否启用着火点检测
    sample_channels:                  # 样品通道映射
      - 0                            # 样品1对应通道0
      - 1                            # 样品2对应通道1
      - 2                            # 样品3对应通道2
      - 3                            # 样品4对应通道3
      - 4                            # 样品5对应通道4
      - 5                            # 样品6对应通道5
    criteria:
      temperature_rise:              # 温度突升法参数
        enabled: true
        threshold: 50.0              # 温升阈值（°C）
        time_window: 2.0             # 时间窗口（秒）
      absolute_temperature:          # 绝对温度法参数
        enabled: true
        threshold: 600.0             # 绝对温度阈值（°C）
      rise_rate:                     # 温升速率法参数
        enabled: true
        threshold: 30.0              # 温升速率阈值（°C/秒）
    check_interval: 0.2             # 检测间隔（秒）
    confirmation_time: 1.0          # 确认时间（秒，预留参数）
```

### 4.3 参数调整建议

**温度突升法阈值**：
- 低挥发性煤：建议40-50°C
- 高挥发性煤：建议50-60°C
- 可根据实际样品特性调整

**时间窗口**：
- 升温速率4.75°C/min：建议2.0秒
- 升温速率较快：建议1.5秒
- 升温速率较慢：建议2.5-3.0秒

**绝对温度阈值**：
- 一般煤粉：建议550-600°C
- 高挥发分煤：建议500-550°C
- 低挥发分煤：建议600-650°C

**温升速率阈值**：
- 一般情况：建议25-30°C/秒
- 快速升温：建议30-40°C/秒
- 慢速升温：建议15-25°C/秒

## 5. 使用操作指南

### 5.1 实验前准备

1. **样品准备**：
   - 准备6份煤粉样品（每份约1-2g）
   - 样品应均匀铺平，厚度约2-3mm
   - 确保样品干燥，无受潮或变质

2. **设备检查**：
   - 检查热电偶是否完好，无损坏
   - 确认热电偶插入样品中心，不接触样品盘底
   - 检查样品架安装是否正确

3. **系统配置**：
   - 进入"参数配置"页面
   - 检查着火点检测参数是否合理
   - 根据样品特性调整检测阈值

### 5.2 实验操作步骤

1. **连接设备**：
   - 点击"连接设备"按钮
   - 等待设备连接成功（状态显示"已连接"）

2. **新建实验**：
   - 点击"新建实验"按钮
   - 填写样品信息和实验参数
   - 确认实验配置

3. **启动实验**：
   - 点击"启动实验"按钮
   - 系统开始升温并监测温度
   - 观察温度曲线和实时数据

4. **监测过程**：
   - 系统自动检测每个样品的着火点
   - 检测到着火点后，对应样品的温度标签会变为红色
   - 着火点信息会显示在样品温度面板上

5. **实验完成**：
   - 所有样品检测完成后，点击"停止实验"
   - 查看实验结果和着火点温度
   - 导出实验数据或生成报告

### 5.3 结果查看

1. **实时显示**：
   - 样品温度面板显示每个样品的当前温度和着火点
   - 温度曲线图显示6个样品的温度变化趋势
   - 实验日志显示检测过程和结果

2. **历史数据**：
   - 进入"历史数据"页面
   - 查询历史实验记录
   - 查看详细的着火点数据

3. **数据导出**：
   - 导出Excel或CSV格式数据
   - 生成HTML格式实验报告
   - 保存温度曲线图

## 6. 技术实现细节

### 6.1 数据结构

**温度历史缓存**：
```python
temp_history = {i: deque(maxlen=200) for i in range(6)}  # 6个通道，每个最多200个点
time_history = deque(maxlen=200)  # 时间历史
```

**检测状态**：
```python
ignition_detected_flags = [False] * 6      # 检测标志
ignition_temperatures = [None] * 6          # 着火温度
last_temperatures = [None] * 6              # 上次温度
last_check_time = time.time()               # 上次检测时间
```

### 6.2 检测算法流程

```python
def _check_ignition():
    # 1. 检查是否启用检测
    if not enabled: return
    
    # 2. 检查检测间隔
    if current_time - last_check_time < check_interval: return
    
    # 3. 遍历6个通道
    for channel in range(6):
        # 跳过已检测的通道
        if ignition_detected_flags[channel]: continue
        
        # 检查数据是否充足
        if len(temp_history[channel]) < 5: continue
        
        # 方法1: 绝对温度法
        if absolute_temperature_enabled:
            if current_temp >= threshold:
                mark_ignition(channel, current_temp, "绝对温度")
                continue
        
        # 方法2: 温度突升法
        if temperature_rise_enabled and len(temp_history) >= 10:
            window_size = time_window / check_interval
            if len(temp_history) >= window_size:
                temp_rise = current_temp - temp_history[-window_size]
                if temp_rise >= threshold:
                    mark_ignition(channel, current_temp, "温度突升")
                    continue
        
        # 方法3: 温升速率法
        if rise_rate_enabled and len(temp_history) >= 3:
            time_diff = check_interval * 2
            temp_diff = current_temp - temp_history[-3]
            rise_rate = temp_diff / time_diff
            if rise_rate >= threshold:
                mark_ignition(channel, current_temp, "温升速率")
                continue
```

### 6.3 标记着火点流程

```python
def _mark_ignition(channel, temperature, method):
    # 1. 更新状态标志
    ignition_detected_flags[channel] = True
    ignition_temperatures[channel] = temperature
    
    # 2. 更新UI显示
    ignition_labels[channel].setText(f"着火点: {temperature:.1f}°C ({method})")
    ignition_labels[channel].setStyleSheet("红色样式")
    temp_labels[channel].setStyleSheet("红色样式")
    
    # 3. 记录日志
    log(f"✓ CH{channel+1} 检测到着火点: {temperature:.1f}°C (方法: {method})")
    
    # 4. 保存到数据库
    db.record_ignition_detection(session_id, channel+1, temperature)
    
    # 5. 发送信号
    ignition_detected.emit(channel, temperature)
```

## 7. 常见问题与故障排除

### 7.1 检测不准确

**问题**：着火点检测结果不准确或误判

**解决方案**：
1. 检查检测参数设置是否合理
2. 确认样品是否均匀铺平，厚度一致
3. 检查热电偶是否插入样品中心
4. 确认升温速率设置是否合适
5. 根据实际样品特性调整检测阈值

### 7.2 检测延迟

**问题**：检测到着火点的时间延迟较大

**解决方案**：
1. 减小检测间隔（check_interval）
2. 降低温度突升阈值
3. 减小时间窗口
4. 提高温升速率阈值灵敏度

### 7.3 误判问题

**问题**：未着火时误判为着火点

**解决方案**：
1. 提高检测阈值
2. 增加时间窗口
3. 检查热电偶是否接触良好
4. 确认样品是否受潮或变质

### 7.4 数据采集问题

**问题**：温度数据不更新或显示异常

**解决方案**：
1. 检查设备连接是否正常
2. 确认串口参数配置正确
3. 检查温度模块通讯是否正常
4. 检查热电偶是否损坏
5. 确认样品通道映射是否正确

## 8. 性能优化建议

### 8.1 检测性能

- **检测间隔**：建议0.2-0.5秒，过小会增加CPU负担
- **数据缓存**：200个点足够，可根据需要调整
- **多方法检测**：建议同时启用2-3种方法，提高准确性

### 8.2 数据采集

- **采集起始温度**：建议200°C，避免无效数据
- **UI更新频率**：500ms足够，过小会影响性能
- **数据库写入**：检测到着火点后立即写入，避免数据丢失

## 9. 安全注意事项

1. **温度限制**：系统设置了600°C的绝对温度上限，超出会报警
2. **设备安全**：实验过程中注意设备温度，避免过热
3. **样品安全**：确保样品干燥，避免受潮引起异常
4. **数据备份**：定期备份实验数据，防止数据丢失
