# 切线法着火点检测功能 - 最终实现方案

## 🎯 核心方案

**独立对话框 + 数据库数据** 方案

这是经过**两次重大优化**后的最终方案，完美解决了所有技术难题。

## 📌 问题演进历史

### 问题1：数据缓存不足（已解决✅）

**发现**：
- 原设计使用 `deque(maxlen=200)` 缓存温度数据
- 90分钟实验只能保存最后1.67分钟数据
- 实验结束时，着火点数据已被挤出

**解决**：
- 从数据库读取完整实验数据
- 数据完整性得到保证

### 问题2：时间轴错位（已解决✅）

**发现**：
- 主图表时间轴：相对时间 [0-100秒]（88.3-90分钟）
- 切线法时间轴：绝对时间 [0-5400秒]（0-90分钟）
- 在主图表上绘制切线会完全错位

**解决**：
- 使用独立对话框显示切线法分析
- 时间轴统一（都基于数据库的绝对时间）
- 完整展示整个实验过程

### 3. 对话框分析逻辑

```python
# src/views/dialogs/tangent_analysis_dialog.py
def _perform_analysis(self):
    """执行分析"""
    # 1. 读取数据库
    session_data = self.db.get_session_temperature_data(self.session_id)
    
    # 2. 构建数组（统一时间轴）
    time_seconds = np.array([r['elapsed_seconds'] for r in session_data])
    time_minutes = time_seconds / 60.0
    
    # 3. 对每个样品分析
    for i in range(6):
        temp_array = np.array([r[f'sample{i+1}_temperature'] for r in session_data])
        result = detector.detect_ignition(time_seconds, temp_array)
        
        # 4. 绘图（统一时间轴）
        self._plot_analysis_result(i, time_minutes, temp_array, result)
```
