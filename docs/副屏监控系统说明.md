# CPIE 副屏监控系统说明

## 系统架构

### 1. 订阅-发布模式

系统采用 Qt 信号-槽机制实现订阅-发布模式，实现主屏与副屏之间的数据同步。

```
控制器 (Controller)
    ↓ (定时轮询设备数据)
    ↓ (发出信号)
监控面板 (Monitor Panel) ← 订阅信号
    ↓
副屏窗口 (Secondary Display Window)
```

### 2. 核心组件

#### 2.1 控制器 (Controllers)

**爆炸性实验控制器** (`explosion_controller.py`)
- 负责爆炸性实验的业务逻辑
- 定时轮询设备数据并发送信号
- 新增信号:
  - `temp_controller_updated(dict)` - 温控器数据
  - `pressure_updated(float)` - 压力数据
  - `relay_status_updated(dict)` - 继电器状态
  - `state_changed(str)` - 实验状态变化
  - `progress_updated(int, str)` - 进度更新
  - `flame_image_updated(object)` - 火焰图像
  - `device_status_changed(str, bool)` - 设备状态

**着火点实验控制器** (`ignition_controller.py`)
- 负责着火点实验的业务逻辑
- 定时轮询设备数据并发送信号
- 新增信号:
  - `control_temp_controller_updated(dict)` - 温控器数据
  - `sample_temps_updated(list)` - 样品温度
  - `state_changed(str)` - 实验状态变化
  - `ignition_detected(float, list)` - 着火检测
  - `device_status_changed(str, bool)` - 设备状态

#### 2.2 监控面板 (Monitor Panels)

**基础监控面板** (`base_monitor_panel.py`)
- 所有监控面板的基类
- 定义通用接口

**爆炸性实验监控面板** (`explosion_monitor_panel.py`)
- 显示温度、压力、火焰图像、实验进度
- 订阅爆炸性控制器的信号

**着火点实验监控面板** (`ignition_monitor_panel.py`)
- 显示炉温、6路样品温度、着火检测
- 订阅着火点控制器的信号

**设备监控面板** (`device_monitor_panel.py`)
- 显示所有设备的在线状态
- 同时订阅两个控制器的信号

#### 2.3 副屏窗口 (Secondary Display Window)

**触摸屏副屏窗口** (`secondary_display_window.py`)
- 1024×600 分辨率设计，自适应缩放
- 三种监控模式切换
- 自动启动/停止数据监控

### 3. 数据流转过程

```
1. 副屏窗口创建
   ↓
2. 调用 controller.start_data_monitoring()
   ↓
3. 控制器启动 QTimer (500ms 间隔)
   ↓
4. 定时器触发 _poll_device_data()
   ↓
5. 从设备管理器获取最新数据
   ↓
6. 发送信号 (emit signals)
   ↓
7. 监控面板接收信号 (槽函数)
   ↓
8. 更新 UI 显示
```

## 使用方法

### 1. 启动副屏监控

主窗口会在启动 1 秒后自动打开副屏窗口：

```python
# 在 MainWindow.__init__ 中
QTimer.singleShot(1000, self._open_secondary_display)
```

### 2. 手动控制数据监控

```python
# 启动数据监控
controller.start_data_monitoring()

# 停止数据监控
controller.stop_data_monitoring()
```

```python

controller.temp_controller_updated.connect(self.on_temp_updated)

    pv = temp_data.get('pv')
    sv = temp_data.get('sv')
    # 更新 UI
```

## 关键优化

### 1. 性能优化

- **定时轮询**: 500ms 更新间隔，平衡实时性和性能
- **数据缓存**: 设备管理器维护最新数据，避免重复查询
- **按需启动**: 仅在副屏打开时启动数据监控

### 2. 线程安全

- **信号-槽机制**: Qt 自动处理跨线程通信
- **QTimer**: 在主线程中轮询，确保 UI 更新安全

### 3. 资源管理

- **自动清理**: 副屏关闭时自动停止数据监控
- **信号断开**: 防止内存泄漏

### 4. 错误处理

- **容错机制**: 数据轮询失败不影响系统运行
- **优雅降级**: 控制器未初始化时延迟重试

### 2. 添加新的控制器信号

```python
# 在控制器中定义信号
custom_data_updated = Signal(dict)

# 在 _poll_device_data() 中发送信号
def _poll_device_data(self):
    data = self.get_custom_data()
    if data:
        self.custom_data_updated.emit(data)
```

## 故障排查

### 1. 副屏无数据显示

- 检查控制器是否正确初始化
- 检查数据监控是否已启动
- 检查信号是否正确连接

### 2. 数据更新延迟

- 调整定时器间隔（默认 500ms）
- 检查设备通信是否正常

### 3. 副屏窗口无法打开

- 检查控制器引用是否正确
- 查看控制台错误信息
- 确认页面已正确初始化

## 技术细节

### 1. 信号数据格式

**温控器数据**:
```python
{
    'pv': float,  # 当前值
    'sv': float,  # 设定值
    'mv': float,  # 输出值
    'status': str  # 状态
}
```

**样品温度数据**:
```python
[temp1, temp2, temp3, temp4, temp5, temp6]  # list of float
```

**继电器状态**:
```python
{
    '1': bool,  # 继电器1状态
    '2': bool,  # 继电器2状态
    '3': bool,  # 继电器3状态
    '4': bool   # 继电器4状态
}
```

### 2. 缩放机制

副屏窗口会根据实际显示器分辨率自动计算缩放比例：

```python
# 基于 1024×600 设计分辨率
width_scale = screen_width / 1024
height_scale = screen_height / 600
scale_factor = min(width_scale, height_scale)

# 限制范围 0.7 ~ 2.5
scale_factor = max(0.7, min(2.5, scale_factor))
```
