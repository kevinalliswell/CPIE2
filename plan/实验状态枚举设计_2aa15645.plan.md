# 实验状态枚举设计计划

## 一、实验流程梳理

### 1.1 爆炸性实验流程

**状态流转：**

```
未连接 (IDLE)
  ↓ [连接设备]
已连接 (CONNECTED)
  ↓ [新建实验]
实验已创建 (SESSION_CREATED) - DB: status='running'
  ↓ [启动实验]
时序运行中 (SEQUENCE_RUNNING) - sequence_running=True, is_running=True
  ↓ [时序完成]
等待分析 (WAITING_ANALYSIS) - sequence_running=False
  ↓ [完成实验]
实验完成 (COMPLETED) - DB: status='completed'
  ↓ [可选：取消/错误]
已取消 (CANCELLED) / 错误 (ERROR)
```

**关键状态点：**

- 设备连接状态：独立于实验状态
- 实验会话状态：数据库中的status字段
- 时序控制状态：sequence_running标志
- 运行状态：is_running标志

### 1.2 着火点实验流程

**状态流转：**

```
未连接 (IDLE)
  ↓ [连接设备]
已连接 (CONNECTED)
  ↓ [新建实验]
实验已准备 (PREPARED) - DB: status='prepared'
  ↓ [启动实验]
实验运行中 (RUNNING) - DB: status='running', is_running=True
  ↓ [停止实验]
实验停止 (STOPPED) - DB: status='completed', is_running=False
  ↓ [可选：取消/错误]
已取消 (CANCELLED) / 错误 (ERROR)
```

**关键状态点：**

- 设备连接状态：独立于实验状态
- 实验会话状态：数据库中的status字段
- 运行状态：is_running标志

## 二、状态枚举设计

### 2.1 ExplosionExperimentState（爆炸性实验状态枚举）

**设计原则：**

1. 区分设备连接状态和实验状态
2. 区分数据库状态和运行时状态
3. 支持状态转换验证
4. 提供状态描述和UI显示文本

**状态定义：**

```python
class ExplosionExperimentState(Enum):
    # 初始状态
    IDLE = "idle"  # 未连接设备
    
    # 设备连接状态
    CONNECTED = "connected"  # 设备已连接
    
    # 实验会话状态
    SESSION_CREATED = "session_created"  # 实验会话已创建
    SEQUENCE_RUNNING = "sequence_running"  # 时序控制运行中
    WAITING_ANALYSIS = "waiting_analysis"  # 等待火焰分析
    COMPLETED = "completed"  # 实验完成
    CANCELLED = "cancelled"  # 实验取消
    ERROR = "error"  # 实验错误
```

### 2.2 IgnitionExperimentState（着火点实验状态枚举）

**设计原则：**

1. 与爆炸性实验类似的结构
2. 适配着火点实验的特殊流程
3. 支持状态转换验证

**状态定义：**

```python
class IgnitionExperimentState(Enum):
    # 初始状态
    IDLE = "idle"  # 未连接设备
    
    # 设备连接状态
    CONNECTED = "connected"  # 设备已连接
    
    # 实验会话状态
    PREPARED = "prepared"  # 实验已准备
    RUNNING = "running"  # 实验运行中
    STOPPED = "stopped"  # 实验已停止
    COMPLETED = "completed"  # 实验完成
    CANCELLED = "cancelled"  # 实验取消
    ERROR = "error"  # 实验错误
```

   - `to_db_status()` 方法

3. **状态描述**

   - `description()` 属性

   - `color()` 属性（用于UI显示）

4. **状态查询**

   - `is_running()` 方法
   - `is_completed()` 方法
   - `can_start()` 方法
   - `can_stop()` 方法
