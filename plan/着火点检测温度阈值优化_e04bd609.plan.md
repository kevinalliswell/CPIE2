# 着火点检测温度阈值优化

## 概述

当前数据采集服务使用起始温度阈值（默认200°C）来控制何时开始采集数据。着火点检测应该采用相同的逻辑，只有温度达到起始温度后才开始检测，避免在低温阶段进行无意义的检测。

## 实现方案

### 1. 修改着火点检测服务接口

**文件**: [`src/services/ignition/ignition_detection_service.py`](src/services/ignition/ignition_detection_service.py)

在 `check_ignition` 方法中：

- 添加 `start_temperature` 参数（可选，默认为0）
- 在检测每个通道前，先判断当前温度是否大于起始温度
- 只有满足温度条件才进行后续的着火点检测逻辑
```python
def check_ignition(self, temp_history: dict, ignition_flags: list, 
                   check_interval: float, start_temperature: float = 0.0):
    # ... 现有逻辑 ...
    
    for i in range(6):
        # ... 现有检查 ...
        
        current_temp = temp_history[i][-1]
        
        # 新增：温度阈值检查
        if current_temp < start_temperature:
            continue
        
        # ... 原有的各种检测方法 ...
```


### 2. 更新调用点传入起始温度

**文件**: [`src/views/pages/ignition_page.py`](src/views/pages/ignition_page.py)

在 `_check_ignition` 方法中：

- 从 `data_collector` 获取起始温度
- 将起始温度作为参数传递给 `check_ignition` 方法

修改位置（第722行附近）：

```python
def _check_ignition(self):
    """检测着火点（使用检测服务）"""
    if not self.ignition_detector:
        return
    
    check_interval = self.config['ignition_detection']['check_interval']
    
    # 获取数据采集起始温度
    start_temp = 0.0
    if self.data_collector:
        start_temp = self.data_collector.get_collect_start_temperature()
    
    # 传入起始温度参数
    results = self.ignition_detector.check_ignition(
        self.temp_history,
        self.ignition_detected_flags,
        check_interval,
        start_temp  # 新增参数
    )
    
    # ... 处理检测结果 ...
```

## 预期效果

- 着火点检测只在温度达到起始温度后才开始
- 与数据采集逻辑保持一致
- 避免低温阶段的无效检测，提高检测效率和准确性
