# 禁用登录并添加删除密码确认

## 修改内容

### 1. 移除登录对话框 - [`src/app.py`](src/app.py)

在应用启动流程中，移除登录对话框的显示和验证逻辑：

```python
# 显示登录对话框
login_dialog = LoginDialog()
if login_dialog.exec() != QDialog.DialogCode.Accepted:
    sys.exit(0)  # 用户取消登录，退出应用
```

**修改方案**：注释掉第30-33行的登录对话框相关代码，使应用直接启动主窗口。

### 2. 创建密码确认对话框 - [`src/views/dialogs/password_confirm_dialog.py`](src/views/dialogs/password_confirm_dialog.py)

**新建文件**：创建一个简单的密码确认对话框，用于删除操作前的密码验证。

**功能**：

- 密码输入框（密文显示）
- 默认密码为 `1952`
- 确认和取消按钮
- 支持 Enter 键确认，Escape 键取消

### 3. 替换权限检查为密码确认 - [`src/views/pages/history_query_page.py`](src/views/pages/history_query_page.py)

在删除实验记录功能中（第852行），将管理员权限检查：

```python
if not user_manager.is_admin():
    QMessageBox.warning(self, "权限不足", "实验员无权删除实验记录！\n只有管理员可以执行删除操作。")
    return
```

**修改方案**：替换为密码确认对话框，只有输入正确密码才能执行删除操作。

### 4. 清理主窗口中的用户管理引用 - [`src/views/main_window.py`](src/views/main_window.py)

在主窗口初始化中（第49-52行），有用户管理相关代码：

```python
self.user_manager = UserManager()
self.current_user = self.user_manager.get_current_user()
```

**修改方案**：注释掉这些代码，因为不再需要用户管理功能。

## 影响范围

- 应用启动时不再需要登录，直接进入主窗口
- 删除操作需要输入密码（1952）确认
- 用户管理模块（`UserManager`）和登录对话框（`LoginDialog`）的代码将保留但不被调用
