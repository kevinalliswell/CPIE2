# 数据记录删除功能增强计划

## 1. 数据库表结构修复

### ignition_database.py

修复 `ignition_detection` 表缺少级联删除的问题：

- 当前：`FOREIGN KEY (session_id) REFERENCES experiment_sessions(id)`
- 修改为：`FOREIGN KEY (session_id) REFERENCES experiment_sessions(id) ON DELETE CASCADE`
- 需要在 `_check_and_upgrade_schema()` 或 `_upgrade_ignition_detection_table()` 中添加升级逻辑

## 2. 扩展删除方法

### explosion_database.py - delete_session()

当前方法仅删除数据库记录（第391-417行），需要扩展：

1. 在删除数据库记录前，查询所有关联的图片路径

- 从 `test_rounds` 表获取 `max_flame_image_path`

2. 删除数据库记录（利用CASCADE自动删除关联表）
3. 删除物理图片文件

- 遍历图片路径列表，删除文件
- 图片位于：`data/max_flame_images/` 目录

### ignition_database.py - delete_session()

当前方法仅删除数据库记录（第525-551行），需要扩展：

1. 在删除数据库记录前，获取 experiment_id

- 从 `experiment_sessions` 表查询

2. 查询所有关联的图片路径

- 从 `ignition_detection` 表获取 `tangent_analysis_image_path`

3. 手动删除 `ignition_detection` 记录（因为缺少CASCADE）
4. 删除数据库记录（CASCADE删除 `ignition_realtime_data`）
5. 删除物理图片文件

- 遍历图片路径列表，删除文件

6. 删除实验文件夹

- 删除整个 `data/analysis_images/{experiment_id}/` 文件夹
- 使用 `shutil.rmtree()` 或逐个文件删除

## 3. UI层调用优化

### history_query_page.py - delete_experiment()

当前方法（第832-891行）已经调用了数据库的 `delete_session()` 方法，但缺少：

1. 增强删除确认对话框，显示将要删除的内容：

- 数据库记录
- 关联图片数量
- 实验文件夹（着火点实验）

2. 删除后刷新详情卡片显示

- 当前只清空了 `self.current_experiment`
- 需要调用详情卡片的 `show_empty_state()` 方法

## 4. 错误处理和日志

为所有删除操作添加完善的错误处理：

- 数据库删除失败时回滚
- 文件删除失败时记录日志但继续执行
- 文件不存在时忽略错误
- 添加详细的日志记录（删除了哪些文件、文件夹）

## 实现要点

1. 爆炸性实验图片散落在 `data/max_flame_images/` 目录，只能逐个删除
2. 着火点实验有专门的 `data/analysis_images/{experiment_id}/` 文件夹，可以整体删除
3. 使用 `os.path.exists()` 检查文件/文件夹是否存在
4. 使用 `os.remove()` 删除单个文件
5. 使用 `shutil.rmtree()` 删除整个文件夹
6. 所有文件操作需要 try-except 保护
