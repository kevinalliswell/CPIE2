# 实验轮次可配置化改造

## 概述

将 `explosion_page.py` 中硬编码的 `max_rounds` 和 `phase_rounds` 改为从配置文件读取，并在 `config_page.py` 中增加对应的UI配置界面。

## 涉及文件

- [`src/views/pages/config_page.py`](src/views/pages/config_page.py) - 添加实验轮次配置UI
- [`src/views/pages/explosion_page.py`](src/views/pages/explosion_page.py) - 修改硬编码为配置读取
- [`configs/experiment_config.yaml`](configs/experiment_config.yaml) - 已包含配置项，无需修改

## 实施步骤

### 1. 在 config_page.py 中添加实验轮次配置UI

在 `_create_explosion_config_tab()` 方法中，在实验条件配置组（第300行）后添加新的配置组：

```python
def _create_test_rounds_group(self):
    """创建实验轮次配置组"""
    group = QGroupBox("实验轮次设置")
    layout = QGridLayout(group)
    
    test_rounds = self.config['explosion_experiment']['test-rounds']
    
    row = 0
    # 最大轮次
    layout.addWidget(QLabel("最大轮次:"), row, 0)
    max_rounds_spin = QSpinBox()
    max_rounds_spin.setRange(1, 50)
    max_rounds_spin.setValue(test_rounds['max-rounds'])
    self.config_widgets['test_max_rounds'] = max_rounds_spin
    layout.addWidget(max_rounds_spin, row, 1)
    
    row += 1
    # 每阶段轮次
    layout.addWidget(QLabel("每阶段轮次:"), row, 0)
    phase_rounds_spin = QSpinBox()
    phase_rounds_spin.setRange(1, 20)
    phase_rounds_spin.setValue(test_rounds['phase-rounds'])
    self.config_widgets['test_phase_rounds'] = phase_rounds_spin
    layout.addWidget(phase_rounds_spin, row, 1)
    
    row += 1
    # 说明信息（国标要求和非标自定义）
    info_label = QLabel(
        "说明:\n"
        "• 国标要求: 最大轮次10轮, 每阶段5轮\n"
        "• 非标自定义: 可根据实验需要调整轮次参数"
    )
    info_label.setStyleSheet("color: #9e9e9e; font-size: 9pt; padding-top: 10px;")
    layout.addWidget(info_label, row, 0, 1, 2)
    
    return group
```

并在 `_create_explosion_config_tab()` 的第300行后调用：

```python
# 实验轮次配置
rounds_group = self._create_test_rounds_group()
layout.addWidget(rounds_group)
```

### 3. 修改 explosion_page.py 从配置读取轮次参数

将第70-71行的硬编码：

```python
self.max_rounds = 10  # 最多10轮
self.phase_rounds = 5  # 每个阶段5轮
```

改为从配置读取：

```python
# 从配置读取实验轮次设置
test_rounds_config = self.config['explosion_experiment'].get('test-rounds', {})
self.max_rounds = test_rounds_config.get('max-rounds', 10)  # 默认10轮（国标要求）
self.phase_rounds = test_rounds_config.get('phase-rounds', 5)  # 默认5轮（国标要求）
```

## 关键点

1. **配置键名**：使用 `test-rounds`、`max-rounds`、`phase-rounds`（与YAML配置文件一致）
2. **国标要求说明**：在UI中明确标注国标要求为10轮/5轮，非标可自定义
3. **向后兼容**：使用 `.get()` 方法提供默认值，确保旧配置文件也能正常工作
4. **值范围**：最大轮次 1-50，每阶段轮次 1-20（合理范围限制）
