# 着火点实验流程优化方案

## 核心修改目标

1. **实时数据更新持久化**：停止/完成实验后，实时数据（温控仪表、样品温度）继续更新
2. **数据采集精确控制**：200℃ ≤ PV < 500℃ 且 RUNNING 状态时写入数据库
3. **会话状态管理优化**：控制器和页面状态同步，完成实验后正确清理
4. **温度曲线清空时机**：从启动实验时清空改为新建实验时清空
5. **按钮布局优化**：启动/停止合并为一个智能按钮，完成实验独立

---

## 核心业务规则（用户需求）

### 规则1：实时数据更新规则

- **触发条件**：设备连接成功后（`manager` 存在）
- **更新内容**：温控仪表数据（PV/SV/MV）、样品温度（6个通道）
- **持续性**：无论实验状态如何（CONNECTED/PREPARED/RUNNING/STOPPED/COMPLETED），只要设备连接，就持续更新
- **定时器**：`update_timer` 从连接设备开始运行，直到应用关闭或断开设备
- **实现位置**：`_update_display()` 方法中无条件调用 `_update_controller_data()` 和 `_update_temperature_data()`

### 规则2：着火检测规则

- **触发条件**：仅在 `is_running=True` 时（RUNNING状态）
- **检测逻辑**：温度突升法、温升速率法
- **实现位置**：`_update_display()` 方法中通过 `if self.is_running:` 判断后调用 `_check_ignition()`

### 规则3：数据采集规则

- **触发条件**：同时满足以下三个条件

                1. `is_running=True`（RUNNING状态）
                2. `session_id` 存在（有活动会话）
                3. `200℃ ≤ PV < 500℃`（温度范围）

- **写入内容**：PV、6个通道温度、时间戳
- **自动停止**：当 PV ≥ 500℃ 时，自动将 `is_running` 设为 False，停止采集
- **实现位置**：`controller.collect_data()` 方法

### 规则4：温度曲线更新规则

- **记录条件**：`is_running=True` 且 `start_time` 存在
- **显示规则**：无论状态，图表始终显示已记录的历史数据
- **清空时机**：新建实验会话时清空（不是启动实验时）
- **实现位置**：`_update_temperature_data()` 方法中通过 `if self.is_running and self.start_time is not None:` 判断

```python
    """启动/停止实验智能处理（根据状态判断）"""
    state = self.controller.current_state
    
    if state == IgnitionExperimentState.PREPARED:
        # 准备状态 -> 启动实验
```

```python
def _finalize_experiment_internal(self):
    """完成实验内部方法"""
    # 1. 检查是否有活动会话
    if not self.current_session_id:
        QMessageBox.warning(self, "提示", "当前没有活动的实验会话")
        return
    
    # 2. 确认对话框（原有代码）
    exp_id = self.current_experiment_config.get('experiment_id', '未知') if self.current_experiment_config else '未知'
    reply = QMessageBox.question(
        self,
        '完成实验',
        f'确定要完成当前实验吗？\n\n'
        f'实验编号: {exp_id}\n'
        f'实验名称: {self.current_experiment_config.get("experiment_name", "未知") if self.current_experiment_config else "未知"}\n\n'
        f'完成后将重置实验状态，可以创建新的实验会话。',
        QMessageBox.Yes | QMessageBox.No,
        QMessageBox.No
    )
    
    if reply == QMessageBox.Yes:
        # 3. 更新状态为COMPLETED（保存到数据库）
        self.controller._set_state(IgnitionExperimentState.COMPLETED)
        db_status = self.controller.current_state.to_db_status()
        if db_status and self.current_session_id:
            self.controller.db.end_experiment_session(self.current_session_id, status=db_status)
        
        # 4. 记录日志
        self._thread_safe_log("=" * 50)
        self._thread_safe_log("✓ 实验已完成")
        self._thread_safe_log(f"  实验编号: {exp_id}")
        self._thread_safe_log("=" * 50)
        
        # 5. 清理会话状态（控制器和页面同步）
        self.controller.reset_session()  # 调用控制器的重置方法
        self.current_session_id = None
        self.current_experiment_config = None
        self.is_running = False
        
        # 6. 重置页面UI状态
        for i in range(6):
            self.ignition_detected_flags[i] = False
            self.ignition_temperatures[i] = None
            self.ignition_labels[i].setText("等待检测")
            self.ignition_labels[i].setStyleSheet("font-size: 10pt; color: #999999;")
        
        # ❌ 删除：不要立即转换为CONNECTED
        # self.controller._set_state(IgnitionExperimentState.CONNECTED)
        
        # 7. 更新按钮状态
        self._update_button_states()
        
        # 8. 更新状态显示
        state = self.controller.current_state
        self._thread_safe_update_status(
            state.display_text(),
            f"font-weight: bold; font-size: 12pt; color: {state.color()};"
        )
        
        # 9. 显示成功消息
        QMessageBox.information(
            self,
            "完成",
            "实验已成功完成！\n\n可以创建新的实验会话进行下一轮实验。"
        )
```

```python
def _update_button_states(self):
    """统一更新所有按钮状态"""
    state = self.controller.current_state
    
    # 连接按钮
    self.btn_connect.setEnabled(state == IgnitionExperimentState.IDLE)

        self.btn_start.setEnabled(True)

    elif state == IgnitionExperimentState.RUNNING:
        self.btn_start.setEnabled(True)
        self.btn_start.setText("停止实验")
        self.btn_start.setObjectName("dangerButton")
    else:
        # 其他状态禁用

        self.btn_start.setText("启动实验")
        self.btn_start.setObjectName("successButton")

    self.btn_finalize.style().polish(self.btn_finalize)
```
