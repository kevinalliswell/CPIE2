# 数据库模块检查与优化建议

## 一、安全漏洞与风险

### 1.1 SQL注入风险（高危）

**问题位置**：

- `explosion_database.py` 第717、725、809行
- `get_all_experiment_sessions()` 和 `get_all_results()` 方法

**问题代码**：

```python
# 第717行
self.cursor.execute(f"""
    SELECT id, experiment_id, start_time, end_time, experiment_name, 
           sample_name, client, operator, description, status
    FROM experiment_sessions
    WHERE status = ?
    ORDER BY {order_by} {order}
""", (status,))

# 第809行
self.cursor.execute(f"""
    SELECT r.id, r.session_id, r.total_rounds, r.avg_flame_length, 
           r.explosion_level, r.timestamp, s.sample_name, s.experiment_name
    FROM experiment_results r
    JOIN experiment_sessions s ON r.session_id = s.id

```

**风险**：`order_by` 参数直接拼接到SQL中，如果用户输入恶意字符串（如 `id; DROP TABLE experiment_sessions; --`），可能导致数据丢失。

**修复方案**：


## 二、数据一致性问题

### 2.1 事务处理不完整

**问题位置**：

- `finalize_experiment()` 方法（第307-358行）

**问题代码**：

```python
def finalize_experiment(self, session_id: int, status: str = 'completed') -> bool:
    try:
        # 获取测试轮次数
        self.cursor.execute("""...""")
        result = self.cursor.fetchone()
        # ... 计算逻辑 ...
        
        # 保存结果
        self.cursor.execute("""INSERT INTO experiment_results ...""")
        
        # 更新会话状态
        self.cursor.execute("""UPDATE experiment_sessions ...""")
        
        self.conn.commit()  # 只有一个commit
```

**问题**：如果中间步骤失败，可能导致部分数据已提交，部分未提交，造成数据不一致。

**修复方案**：

```python
def finalize_experiment(self, session_id: int, status: str = 'completed') -> bool:
    try:
        # 开始事务（SQLite默认自动提交关闭，但显式声明更清晰）
        # 获取测试轮次数
        self.cursor.execute("""...""")
        result = self.cursor.fetchone()
        if not result or result[0] == 0:
            self.logger.error(f"✗ 会话 {session_id} 没有测试数据")
            self.conn.rollback()  # 显式回滚
            return False
        
        # ... 计算逻辑 ...
        
        # 保存结果
        self.cursor.execute("""INSERT INTO experiment_results ...""")
        
        # 更新会话状态
        self.cursor.execute("""UPDATE experiment_sessions ...""")
        
        self.conn.commit()
        return True
    except sqlite3.Error as e:
        self.logger.error(f"✗ 完成实验失败: {e}")
        self.conn.rollback()  # 确保回滚
        return False
```

### 2.2 并发写入冲突

**问题位置**：

- 数据库连接使用 `check_same_thread=False`，允许多线程访问

**问题**：SQLite在多线程并发写入时可能出现 `database is locked` 错误。

**修复方案**：

```python
def _connect(self):
    """连接数据库"""
    try:
        # 设置超时时间，避免长时间锁定
        self.conn = sqlite3.connect(
            self.db_path, 
            check_same_thread=False,
            timeout=10.0  # 10秒超时
        )
        self.cursor = self.conn.cursor()
        # 启用WAL模式，提高并发性能
        self.cursor.execute("PRAGMA journal_mode=WAL")
        # 启用外键支持
        self.cursor.execute("PRAGMA foreign_keys = ON")
        self.logger.info(f"✓ 数据库连接成功: {self.db_path}")
    except sqlite3.Error as e:
        self.logger.error(f"✗ 数据库连接失败: {e}")
        raise
```

## 三、业务逻辑问题

### 3.1 轮次编号重复检查缺失

**问题位置**：

- `add_test_round()` 方法（第203-230行）

**问题**：没有检查同一会话中是否已存在相同轮次编号的记录，可能导致重复数据。

**修复方案**：

```python
def add_test_round(self, session_id: int, round_number: int, 
                  flame_length: float, max_flame_image_path: str = None) -> int:
    """添加一轮测试数据"""
    try:
        # 检查是否已存在该轮次
        self.cursor.execute("""
            SELECT id FROM test_rounds 
            WHERE session_id = ? AND round_number = ?
        """, (session_id, round_number))
        
        existing = self.cursor.fetchone()
        if existing:
            self.logger.warning(f"⚠ 会话 {session_id} 第 {round_number} 轮已存在，将更新")
            # 更新现有记录
            self.cursor.execute("""
                UPDATE test_rounds 
                SET flame_length = ?, max_flame_image_path = ?, timestamp = CURRENT_TIMESTAMP
                WHERE id = ?
            """, (flame_length, max_flame_image_path, existing[0]))
            self.conn.commit()
            return existing[0]
        
        # 插入新记录
        self.cursor.execute("""
            INSERT INTO test_rounds 
            (session_id, round_number, flame_length, max_flame_image_path)
            VALUES (?, ?, ?, ?)
        """, (session_id, round_number, flame_length, max_flame_image_path))
        
        self.conn.commit()
        self.logger.info(f"✓ 第{round_number}轮测试数据已记录: 火焰长度={flame_length}mm")
        return self.cursor.lastrowid
    except sqlite3.Error as e:
        self.logger.error(f"✗ 添加测试轮次失败: {e}")
        self.conn.rollback()
        return -1
```

### 4.2 批量操作优化

**问题位置**：

- `add_batch_test_rounds()` 方法（第232-259行）

**问题**：使用 `executemany` 但缺少事务保护。

**修复方案**：

```python
def add_batch_test_rounds(self, session_id: int, 
                         rounds_data: List[Tuple[int, float, str]]) -> int:
    """批量添加测试轮次数据"""
    try:
        data_with_session = [(session_id, r[0], r[1], r[2]) for r in rounds_data]
        
        # 使用事务批量插入
        self.cursor.executemany("""
            INSERT OR REPLACE INTO test_rounds 
            (session_id, round_number, flame_length, max_flame_image_path)
            VALUES (?, ?, ?, ?)
        """, data_with_session)
        
        self.conn.commit()
        count = len(rounds_data)  # 使用实际插入数量
        self.logger.info(f"✓ 批量添加 {count} 轮测试数据")
        return count
    except sqlite3.Error as e:
        self.logger.error(f"✗ 批量添加测试轮次失败: {e}")
        self.conn.rollback()
        return 0
```

## 六、资源管理

### 6.1 连接泄漏风险

**问题位置**：

- `__del__` 方法中调用 `close()`

**问题**：`__del__` 方法在对象销毁时调用，但此时 `self.logger` 可能已不可用。

**修复方案**：

```python
def __del__(self):
    """析构函数"""
    try:
        if self.conn:
            self.conn.close()
    except Exception:
        pass  # 忽略析构时的错误
```

### 6.2 备份操作缺少错误处理

**问题位置**：

- `backup()` 方法（第957-974行）

**问题**：备份失败时只记录日志，没有抛出异常或返回详细错误信息。

**修复方案**：

```python
def backup(self, backup_path: str) -> bool:
    """备份数据库"""
    try:
        import shutil
        import os
        
        # 确保备份目录存在
        backup_dir = os.path.dirname(backup_path)
        if backup_dir and not os.path.exists(backup_dir):
            os.makedirs(backup_dir, exist_ok=True)
        
        # 先关闭连接，确保数据已写入
        if self.conn:
            self.conn.commit()
            self.conn.close()
        
        # 复制文件
        shutil.copy2(self.db_path, backup_path)
        
        # 重新连接
        self._connect()
        
        self.logger.info(f"✓ 数据库已备份到: {backup_path}")
        return True
    except Exception as e:
        self.logger.error(f"✗ 数据库备份失败: {e}")
        # 重新连接（如果备份时关闭了连接）
        if not self.conn:
            try:
                self._connect()
            except Exception:
                pass
        return False
```
